# 🚀 Google Flow Unlocker

Браузерное расширение для **Google Chrome** (и любых Chromium-браузеров) и **Mozilla Firefox**, которое снимает региональные ограничения и восстанавливает доступ к творческой ИИ-студии **Google Flow** (`flow.google.com`) из России и Беларуси.

---

## 📋 Как это работает

При входе на `flow.google.com` из РФ и РБ пользователи сталкиваются с экраном блокировки:
> *"Flow isn't available in your country yet"* (или автоматическим редиректом на `/unsupported-country`).

Внутри фронтенд-бандла Google Flow (`AiSandboxAngularFrontend`) заложена клиентская проверка региона (флаг `31`), которая проверяет геолокацию и принудительно перенаправляет пользователя на страницу заглушки.

**Что делает это расширение:**
1. **Перехватывает загрузку бандла Google Flow**:
   - В **Chrome / Chromium**: через Chrome DevTools Protocol (`chrome.debugger` + `Fetch.enable`).
   - В **Firefox**: через нативный потоковый фильтр `browser.webRequest.filterResponseData()`, работающий без баннеров отладки и с нулевой задержкой.
2. **Патчит проверку на лету**: заменяет вызов проверки региона `_.XX(arg, 31)` на `true` и нейтрализует Angular route guard для `/unsupported-country`.
3. **Предотвращает петли редиректов**: при попытке браузера уйти на страницу ошибки моментально возвращает на главную страницу студии.

## 📂 Структура проекта

- **`chrome/`** — Исходный код расширения для Chrome, Яндекс.Браузера, Edge, Brave, Opera (Manifest V3).
- **`firefox/`** — Исходный код расширения для Mozilla Firefox (Manifest V3 с `webRequestFilterResponse`).
- **`dist/`** — Готовые к установке архивы:
  - `google-flow-unlocker-chrome.zip`
  - `google-flow-unlocker-firefox.zip` (и `.xpi`)
- **`build_packages.ps1`** — Скрипт сборки архивов в папку `dist/`.

## 🛠️ Инструкция по установке

### 1. Установка в Google Chrome / Яндекс.Браузер / Edge / Brave

1. Откройте в браузере страницу расширений:
   - В Chrome: `chrome://extensions/`
   - В Яндекс.Браузере: `browser://tune/` или `chrome://extensions/`
   - В Microsoft Edge: `edge://extensions/`
2. Включите переключатель **«Режим разработчика»** (Developer Mode) в правом или левом углу страницы.
3. Либо:
   - Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) и выберите папку [`chrome`](file:///c:/Users/USER/Desktop/Анлок Flow/chrome).
   - *Или* просто перетащите файл `dist/google-flow-unlocker-chrome.zip` прямо в окно браузера на странице расширений.
4. Расширение установлено и автоматически переведено в статус **«ВКЛ»**.

---

### 2. Установка в Mozilla Firefox

1. Откройте в адресной строке Firefox:
   ```text
   about:debugging#/runtime/this-firefox
   ```
2. Нажмите кнопку **«Загрузить временное дополнение…»** (Load Temporary Add-on...).
3. Выберите файл [`manifest.json`](file:///c:/Users/USER/Desktop/Анлок Flow/firefox/manifest.json) из папки `firefox` (или архив `dist/google-flow-unlocker-firefox.zip`).
4. Расширение появится в панели Firefox.

> **Преимущество версии для Firefox**: благодаря нативному API `filterResponseData()`, в Firefox вообще не появляется предупреждающая плашка браузера об отладке (которую Chrome выводит при использовании CDP).

## 🌐 Важный шаг: Настройка DNS (если сайт не открывается)

Российские интернет-провайдеры могут блокировать первичное обращение к доменам `flow.google.com`. Если сайт выдает ошибку таймаута соединения или не открывается вообще:

Вам **не обязательно** включать медленный VPN — достаточно включить **Безопасный DNS (DNS-over-HTTPS)** прямо в настройках браузера:

### В Chrome / Edge / Яндекс:
1. Зайдите в **Настройки** → **Конфиденциальность и безопасность** → **Безопасность**.
2. В разделе **«Использовать безопасный DNS-сервер»** выберите **«Пользовательский»**.
3. Вставьте любой надежный DoH-резолвер, например:
   ```text
   https://cloudflare-dns.com/dns-query
   ```
   *(или `https://dns.google/dns-query`, или `https://dns.bezmezhau.com/dns-query`)*

### В Firefox:
1. Зайдите в **Настройки** → вкладка **«Основные»** → прокрутите вниз до **«Параметры сети»** → кнопка **«Настроить…»**.
2. В самом низу включите галочку **«Включить DNS через HTTPS»**.
3. Выберите **«Повышенная защита»** или **«Максимальная защита»** и поставьте резолвер Cloudflare или укажите свой.

После этого `flow.google.com` будет открываться на полной скорости вашего интернет-соединения!

## ⚠️ Диагностика частых ситуаций

| Что вы видите | Причина | Что делать |
| :--- | :--- | :--- |
| **«Flow isn't available in your country yet»** | Сработала клиентская проверка региона. | Убедитесь, что расширение включено (горит значок **ВКЛ**). Перезагрузите страницу с зажатым `Ctrl+F5`. |
| **«Похоже, у вас нет доступа к Flow»** | Серверная проверка Google. Расширение уже успешно сняло региональный экран, но у аккаунта нет доступа к сервису. | Google Flow требует подтвержденного возраста (18+) и/или активной подписки Google AI Pro/Ultra на аккаунте. Проверьте статус вашего Google-аккаунта. |
| **Сайт долго грузится и выдает ошибку соединения** | Провайдер глушит домен Google Flow. | Включите DoH (безопасный DNS) по инструкции выше или воспользуйтесь прокси/VPN. |

## 💻 Сборка из исходников

Если вы вносили изменения в код и хотите пересобрать архивы, запустите в PowerShell:
```powershell
.\build_packages.ps1
```
Готовые `.zip` и `.xpi` будут обновлены в папке `dist/`.
